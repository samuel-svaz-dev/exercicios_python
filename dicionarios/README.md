Esta pasta contém resoluções de exercícios práticos focados na estrutura de dados de **Dicionários** (`dict`) em Python, desenvolvidos durante o meu aprendizado.

---

## 📚 Conteúdo

Selecione um dos desafios abaixo para visualizar a implementação do código:

*   [**Cadastro de Trabalhador**](./cadastro-trabalhador) – Exercício focado em estruturação de dados de funcionários e CTPS.
*   [**Cadastro de Pessoas e Análise**](./cadastro_pessoas.py) – Script para captação de dados grupais (nome, sexo, idade) com estatísticas finais.
*   [**Contador de Gols e Jogadores**](./contador_gols_jogos.py) – Sistema para gerenciar o aproveitamento de jogadores de futebol, calculando partidas e gols.

---

## 🎯 Objetivo

Praticar de forma intensiva a utilização de dicionários no Python, compreendendo como mapear chaves e valores para modelar problemas do mundo real de forma eficiente.

---

## 🧠 Habilidades Desenvolvidas

*   Manipulação avançada de dicionários (métodos `.keys()`, `.values()`, `.items()`).
*   Aninhamento de estruturas compostas (Dicionários dentro de Listas).
*   Uso refinado de laços de repetição (`for` / `while`) e estruturas condicionais.
*   Validação de dados e lógica de programação aplicada.

---
